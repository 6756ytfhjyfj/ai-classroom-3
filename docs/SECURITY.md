# 安全与部署边界

SQLite 随桌面运行是单机模式。持有 Windows 用户权限的本机所有者能够修改程序或数据库，不能将本机后端称为跨设备的可信注册服务。学校或多人环境应运行独立的 PostgreSQL 服务端，通过 HTTPS 接入，禁止学生控制服务器文件和环境。

设备身份是服务端签发的随机恢复凭证，客户端 DPAPI 加密，服务端 SHA-256 摘要。保留设备凭证的重装会恢复既有名额；丢失凭证不能从硬件重新识别。集中部署使用 `DEVICE_ENROLLMENT_MODE=admin`，所有未知安装必须导入管理员签发的凭证；禁止匿名无限申请新设备。仅本地演示允许 `open-demo` 自动创建设备，界面与说明均标明范围。不能承诺硬件层不可绕过。

设备名额由 slot ∈ {1,2,3} 及 deviceId+slot 唯一约束保证。事务更新设备记录后选择空槽，数据库限制保护其他并发客户端。注销、冻结、账号删除不自动释放槽。管理员必须输入设备 ID 与原因才能重置，记录原绑定与审计。重绑定旋转设备凭证并撤销设备会话。

用户名 NFKC 标准化与唯一索引；Argon2id（19MiB、2迭代、并行度1）密码散列；至少10字符。会话 256-bit 随机令牌，数据库仅存 SHA-256；HttpOnly、SameSite=Strict、HTTPS集中部署启用 Secure。关键接口限流，写请求验证 Origin/Sec-Fetch-Site，所有后台接口服务端检查 ADMIN。反向代理须正确配置可信代理地址后再启用 trustProxy，避免伪造 IP；本版默认不信任代理头。

模型 Key AES-256-GCM（随机12-byte IV），加密主密钥必须备份。集中部署由环境注入；桌面使用 DPAPI 保护。API只返回掩码，错误日志不打印请求体、令牌或上游完整错误。模型自定义主机必须 HTTPS 且在服务器允许列表，禁止重定向认证请求。生产环境应在主机网络层进一步限制出站与 DNS，防止被授权主机本身遭到攻击。

管理员初始化仅可由服务器所有者 CLI，或桌面启动参数 `--initialize-admin` 的一次性随机引导通道进行，无默认口令；引导完成后通道失效。账号恢复码随机256-bit，只存摘要，使用一次后轮换并撤销所有会话。人工恢复先核验申请人身份；不能仅凭用户名申请直接改密。

课堂、聊天、笔迹、实验 API 全部检查 userId 归属。IndexedDB 草稿按 userId/classroomId 命名空间。云端手写识别、原图提问需要一次性明确授权。文本问题发送及当前实验上下文是点击发送的预期行为。Windows 本地语音使用系统语言包；网页系统语音可能外发，须额外授权。原始录音不存储、不上传自有服务端；图片只用于本次模型请求，不长期放入聊天表，原始笔迹文档仍可恢复。

管理员审核账号删除后：删除课堂、消息、草稿和实验；匿名化账号；保留占用名额绑定与必要审计。设备记录保留到学校策略规定的审计周期，部署方应公布具体保留期限并安排清理任务。本版未配置外部定期清理服务。

Electron 开启 sandbox/contextIsolation，关闭 Node renderer，固定IPC白名单并验证 senderFrame.origin。DPAPI只能防止离线直接读取，不能防止同一 Windows 用户或恶意本机程序。未签名安装包的来源需要用户自行核验，正式分发应购买代码签名证书并在构建机配置签名。
