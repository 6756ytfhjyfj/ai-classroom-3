# AI Classroom 简易使用指南

网页版：**https://ai-classroom-3-sand.vercel.app**

Windows 下载：[GitHub Releases](https://github.com/6756ytfhjyfj/ai-classroom-3/releases/tag/v3.0.0) · [完整源码](https://github.com/6756ytfhjyfj/ai-classroom-3)

## 第一次配置（项目所有者）

1. 使用交付给你的**私密一次性初始化链接**，设置管理员用户名和密码。没有公开默认密码，初始化链接请勿转发。
2. 进入网页的 `/admin` 后台，在 AI 服务中选择 DeepSeek 或 Gemini，填写你自己的 API Key、可用模型 ID，保存并点击“真实连接测试”。Gemini AQ 密钥可以直接填写，不要修改前缀。
3. 将模型分配给学科。手写图片识别需要支持图片的模型，开启对应图片能力；纯文字模型不能识别笔迹图片。
4. 访问网站首页，选择学科即可开始。管理员账号也可以进入课堂。

未配置密钥时，手写与本地计算实验仍然可用；AI 会明确提示“尚未配置”，不会生成假回答。请在后台直接配置密钥，不要放进 GitHub、聊天或前端代码。

## 学生怎么进入

1. 由管理员在“设备与注册名额”中审核并签发设备恢复凭证。
2. 学生打开网站，在登录页导入凭证，再注册用户名和密码；注册后妥善保存一次性账号恢复码。
3. 每个已批准的设备身份最多注册 3 个学生账号。退出登录、冻结或申请删除不自动释放名额。
4. 凭证丢失或换浏览器时联系管理员审核恢复，不要重复申请新设备来绕过限制。浏览器本身不能证明同一台物理电脑。

设备凭证用于恢复设备身份，不能代替登录密码。不同学生必须使用各自账号。

## 上课的五个操作

- **选学科**：数学、物理、化学、生物、语文、英语；历史课堂可继续打开。
- **手写**：点击“手写”或按 `Ctrl + Shift + H`，直接在全屏白板写。可以撤销、重做、保存并返回。识别候选可修改，确认后才提交。
- **语音**：点击麦克风或按 `Ctrl + Shift + M`，阅读权限提示后主动开启；识别文字可以修改，再手动发送。网页语音能力受浏览器和系统语言包影响，优先用新版 Edge。
- **打断**：点击打断、按 `Esc` 或进入手写，立即停止当前朗读和可取消请求。
- **做实验**：数学调函数参数；物理拖动元件、连接电路并调整电阻；化学演示离子形成或输入化学方程式配平。实验会真实计算并保存状态。

`Ctrl + Enter` 提交，手写中 `Ctrl + Z` 撤销、`Ctrl + Y` 重做。不要在未确认时发送原始笔迹、图片或语音到云端。

## Windows 安装版

下载 `AI-Classroom-3.0.0-Setup.exe`，对照仓库中的 [SHA256SUMS.txt](../SHA256SUMS.txt) 校验后安装。安装包目前未做商业代码签名。单机版的数据和账号独立保存在本机，与公网版不会自动同步。

单机版首次配置管理员：退出应用后，在 PowerShell 使用实际安装路径启动：

```powershell
& 'C:\你的安装目录\AI Classroom.exe' --initialize-admin
```

以后使用 `--admin` 进入后台。若要用桌面客户端连接公网服务，关闭软件后运行：

```powershell
$env:CLASSROOM_SERVER_URL='https://ai-classroom-3-sand.vercel.app'
& 'C:\你的安装目录\AI Classroom.exe'
```

集中模式仍须导入管理员签发的设备凭证。不会自动迁移已有单机数据。

## 常见情况

- **AI 不能回答 / 识别不可用**：管理员检查真实连接测试、余额、权限、模型名称和图片能力。密钥由你自己的模型服务计费。
- **设备尚未绑定**：导入审核后的设备凭证；有 3 个账号后只能登录已有账号或申请管理员处理。
- **网页暂时打不开**：检查网络后重试。免费托管有资源和休眠限制，目前是工程预览版；Windows 安装版可独立使用。
- **历史与草稿**：课堂记录在云端账号中保存，未提交草稿也会保存在当前浏览器。清理浏览器数据前先导出重要笔迹并保管设备凭证。
- **更新网页**：当前已发布源码和公网部署。Vercel 尚未绑定 GitHub Login Connection，单纯推送 GitHub 不会自动更新网站；可在 Vercel 完成 GitHub 绑定，或按 `CLOUD-DEPLOYMENT.md` 重新部署。

真实数位板、麦克风、云端模型和识别精度仍需在你的实际设备与密钥下验证。没有模型密钥时无法完成真实 AI 对话验收。
