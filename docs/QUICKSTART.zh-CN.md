# ONclasstime 简易使用指南

1. 打开 https://onclasstime.vercel.app ，点击下载 Windows 安装包。
2. 运行安装程序，选择安装位置和桌面快捷方式，完成后启动。
3. 用用户名和密码注册；保存弹出的恢复码，忘记密码时用它找回。没有设备绑定和三账号限制。
4. 在“练习题库”选择学科、知识点与难度，输入答案后核对。答错会自动加入“我的错题”。
5. 在“我的错题”上传作业图片，确认上传后保存；可写订正、标记掌握、安排复习，或摘录到笔记。图片不会自动发给 AI。
6. 在“笔记本”新建本子与笔记，输入内容后自动同步。可预览 Markdown/公式，Ctrl+S 保存，也可以导出。
7. 选择学科进入课堂，使用键盘、手写或语音提问。手写 Ctrl+Shift+H，提交 Ctrl+Enter，Esc 返回。

AI 模型需要管理员在独立管理站 https://onclasstime-admin.vercel.app 配置可用 DeepSeek/Gemini 密钥与模型。没有配置时会明确提示。

单张错题图片上限 2 MB，账号图片总额 20 MB；客户端会先压缩。账号与云端资料需要联网。退出或断网时，本机草稿会尽量保留，网络恢复后请确认同步状态。卸载通过 Windows“已安装的应用”，完整卸载可清除本机资料，云端账号与资料保留。

首次管理员应由部署所有者用私密的一次性初始化链接设置；没有公开默认密码。
