# 3.1 变更与验收

产品改名 ONclasstime；用户提供蓝青 Logo，界面与安装器附 `Power By ONtimeclass`。

1. 用户名密码注册登录，不再执行设备注册或三账号限制。
2. 公开首页作为下载站，学生在安装后的 Windows 程序中学习。
3. 管理站为独立公网项目，程序不包含管理页面；敏感接口依旧逐项校验角色。
4. 新增 157,011 道原创可计算变式与六学科基础题，以及管理员 JSON 导入。实际题数经过全量唯一性检查；这不等同于同数量的不同知识点或历年真题。
5. 题目判分、解析、错题自动归档；图片上传、私有读取、订正与复习；笔记本、自动保存、搜索、置顶、Markdown/公式预览和导出。
6. Windows WPF 安装向导提供路径选择、快捷方式、SHA-256 校验、真实解压进度、取消和卸载，保留用户资料。

自动化：29 项单元/真实数据库集成测试，涵盖账号隔离、无设备注册、答案判分、全量题库唯一性与分页、错题图片类型与权限、笔记并发版本保护、后台导入与密钥脱敏。浏览器端到端覆盖注册至笔记刷新恢复；安装后客户端另行执行同一路径验证。

真实限制：未提供可用 AI 服务密钥，无法把真实推理或 AQ 密钥认证记为通过。数位板压感、Windows 原生语音识别、回声处理需要具体设备与语言包验收。安装器未商业签名；本机草稿和云端资料并非离线完整镜像。
